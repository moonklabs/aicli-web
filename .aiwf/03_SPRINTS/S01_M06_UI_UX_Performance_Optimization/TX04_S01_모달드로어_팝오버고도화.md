# Task: 모달드로어 팝오버고도화

## Description
고급 오버레이 컴포넌트 시스템을 구축하여 모달, 드로어, 팝오버, 툴팁 등의 오버레이 UI 컴포넌트를 표준화하고 고도화합니다. 애니메이션, 포커스 관리, 접근성, 스택 관리 등을 포함한 엔터프라이즈급 오버레이 시스템을 구현합니다.

## Goal / Objectives
- 통합된 오버레이 관리 시스템 구축
- 모달, 드로어, 팝오버, 툴팁 컴포넌트 고도화
- 포커스 트랩 및 키보드 네비게이션 완벽 지원
- 오버레이 스택 관리 및 z-index 자동 관리
- 부드러운 애니메이션 및 트랜지션 효과

## Technical Guidelines

### 주요 기술 스택
- **프레임워크**: Vue 3 + Composition API
- **타입 시스템**: TypeScript 5.x
- **애니메이션**: CSS Transitions + Vue Transition API
- **포지셔닝**: @floating-ui/vue
- **테스트**: Vitest + Vue Test Utils
