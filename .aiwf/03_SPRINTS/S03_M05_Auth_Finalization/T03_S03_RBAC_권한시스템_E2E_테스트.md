# Task: RBAC 권한 시스템 E2E 테스트

## Description
역할 기반 접근 제어(RBAC) 시스템의 포괄적인 E2E 테스트를 구현합니다. 사용자 역할 할당, 권한 상속, 리소스 접근 제어, 동적 권한 검증, 그리고 권한 기반 UI 렌더링을 검증하여 세밀한 권한 관리 시스템의 정확성을 보장합니다.

## Goal / Objectives
RBAC 시스템의 완전한 E2E 테스트 커버리지를 달성하여 세밀하고 안전한 권한 관리 시스템 동작을 보장
- 사용자 역할 할당 및 권한 상속 E2E 테스트 구현
- 리소스별 접근 제어 및 API 권한 검증 E2E 테스트
- 프론트엔드 권한 기반 UI 렌더링 E2E 테스트
- 동적 권한 변경 및 실시간 반영 E2E 테스트

## 기술 가이드

### 주요 인터페이스 및 통합 지점
- **권한 검증 API**: `/api/v1/auth/permissions`, `/api/v1/auth/roles`
- **RBAC 미들웨어**: `internal/auth/rbac/middleware.go`
- **권한 관리 서비스**: `internal/auth/rbac/service.go`
- **프론트엔드 권한 디렉티브**: `v-permission`, 라우트 가드
- **권한 캐시**: Redis 기반 권한 정보 캐싱

### RBAC 데이터 모델
- **User**: 사용자 정보 및 역할 연결
- **Role**: 역할 정의 및 권한 집합
- **Permission**: 세밀한 권한 정의
- **RolePermission**: 역할-권한 매핑
- **UserRole**: 사용자-역할 매핑

### 기존 패턴 활용
- S01에서 구현된 RBAC 데이터 모델 및 권한 로직
- S02에서 구현된 프론트엔드 권한 기반 UI 시스템
- 기존 권한 검증 테스트 패턴 확장
