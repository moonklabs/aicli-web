# Task: E2E 인증 플로우 테스트 구현

## Description
고급 인증 시스템의 핵심 인증 플로우(로그인, 로그아웃, 토큰 갱신, 세션 관리)에 대한 포괄적인 E2E 테스트를 구현합니다. 프론트엔드와 백엔드 간의 완전한 통합을 검증하고, 실제 사용자 시나리오를 시뮬레이션하여 인증 시스템의 신뢰성을 확보합니다.

## Goal / Objectives
완전한 E2E 인증 테스트 스위트를 구축하여 M05 마일스톤의 인증 시스템이 실제 운영 환경에서 안정적으로 작동함을 보장
- 모든 기본 인증 플로우에 대한 자동화된 E2E 테스트 작성
- 프론트엔드-백엔드 통합 검증 및 API 계약 테스트
- 실제 사용자 시나리오 기반 테스트 시나리오 구현
- CI/CD 파이프라인에서 실행 가능한 테스트 인프라 구축

## 기술 가이드

### 주요 인터페이스 및 통합 지점
- **백엔드 API**: `/api/v1/auth/*` 엔드포인트들
- **프론트엔드 컴포넌트**: 로그인 폼, 인증 상태 관리, 토큰 처리
- **미들웨어**: JWT 인증, CSRF 보호, Rate Limiting
- **데이터베이스**: 사용자 인증 정보, 세션 데이터, 블랙리스트

### 테스트 프레임워크 및 도구
- **E2E 프레임워크**: Playwright 또는 Cypress
- **API 테스트**: Go 테스트 프레임워크 + testify
- **테스트 데이터**: Factory 패턴 활용한 테스트 데이터 생성
- **환경 설정**: Docker Compose를 활용한 격리된 테스트 환경

### 기존 패턴 활용
- S01과 S02에서 구현된 인증 API 및 프론트엔드 컴포넌트 활용
- 기존 테스트 패턴 (`*_test.go`) 확장
- 통합 테스트에서 사용된 Mock 패턴 재사용
